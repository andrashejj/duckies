# Sunset Surfers

Landing site for a volunteer-run, member-funded surf club for kids in Tamarin, Mauritius. (Previously "Duckies Surf Club".)

## Stack

- Astro
- Tailwind CSS via `@tailwindcss/vite`
- Motion for entrance and scroll effects
- Build-time QR code generation with `qrcode`

## Routes

- `/`
- `/training-materials`

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`
